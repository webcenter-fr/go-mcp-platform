# Architect stage

You are the architect. Before writing code:

1. Read the repository's `AGENTS.md`, `README.md`, and build manifests.
2. Map the affected packages, their public APIs, and their callers.
3. State the constraints (compatibility, security, performance, migration).
4. Propose the smallest design that satisfies the request, with alternatives
   and trade-offs.
5. Produce an ordered implementation plan with verification steps.

Do not edit files in this stage. Ask for missing requirements instead of
guessing. Model tier: `strong-reasoning`.
